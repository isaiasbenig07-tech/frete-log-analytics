# 🚛 Transportadora Freight & Cost Analytics Lab

Projeto focado em **Análise de Custos e Gestão Financeira para Transportadoras**, automatizando a consolidação de fretes brutos, repasses a motoristas terceirizados, consumo de combustível (diesel) e apuração de margem de lucro líquido.

---

## 📂 Estrutura do Repositório

| Ficheiro / Diretório | Descrição |
| :--- | :--- |
| [`data/fretes_2026.csv`](data/fretes_2026.csv) | Base de dados mensal com faturamento, terceiros, combustível e manutenção. |
| [`scripts/analisar_fretes.py`](scripts/analisar_fretes.py) | Script em Python com Pandas para apurar custos, lucro e margem operacional. |
| 📊 Planilha Operacional | /dados/transportadora-gestao-fretes-lucro.xlsx |

---

## 📊 Indicadores Acompanhados
* **Repasse a Terceiros:** Percentual do faturamento comprometido com terceirizados/agregados.
* **Eficiência de Combustível:** Impacto do diesel na margem de contribuição.
* **Margem Líquida Operacional:** Rentabilidade real da operação após todos os custos diretos.
